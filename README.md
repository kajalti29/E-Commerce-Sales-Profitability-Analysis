# E-Commerce Sales & Profitability Analysis Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze e-commerce sales, profitability, orders, quantity, and payment trends.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Profit Margin %
- Total Quantity

## Dashboard Analysis
- Sales by Category
- Sales by City
- Profit by Category
- Sales by Payment Mode
- Region-wise analysis
- Order Status analysis

## Key Features
- Interactive slicers
- KPI cards
- Dynamic charts
- Data cleaning using Power Query
- DAX measures for business metrics
